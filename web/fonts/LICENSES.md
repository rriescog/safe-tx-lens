# Bundled fonts

These Latin-subset WOFF2 files are served from this origin so the strict
Content-Security-Policy needs no third-party font host. All are licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org) and were
copied unmodified from the Fontsource npm packages.
